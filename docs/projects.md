# Active Projects

## Project Atlas

Project Atlas is a recommendation engine that relies on semantic search to
match users with relevant content. It is built on top of the company's
vector database infrastructure. The project is led by Marcus Webb.

## Project Kestrel

Project Kestrel is a high-throughput data ingestion service written in Rust,
backed by a PostgreSQL database. It was designed and implemented primarily
by Priya Patel.

## Project Beacon

Project Beacon is the internal deployment platform, orchestrated with
Kubernetes and provisioned with Terraform. Sofia Ramos owns this project
end-to-end, from infrastructure design to on-call support.
